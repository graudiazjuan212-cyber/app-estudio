5. **Enrutado por hash (ADR-004)** en `src/domain/router.ts`, función pura `parseRoute(hash: string): Route` con:
   ```ts
   type Route =
     | { name: 'home' }
     | { name: 'subject'; subjectId: string }
     | { name: 'session'; subjectId: string; mode: 'auto' | 'review' | 'exam'; chapterId?: string }
     | { name: 'settings' };
   ```
   Formatos: `#/` y vacío → home; `#/ajustes` → settings; `#/asignatura/<id>` → subject; `#/sesion/<id>` → session auto; `#/sesion/<id>/repasar/<capId>` → review con capítulo; `#/sesion/<id>/examen/<capId>` → exam. Ids con `decodeURIComponent` seguro (un `%` mal formado no debe lanzar excepción: devuelve home). Cualquier otra cosa → home. También `buildHash(route: Route): string` inverso, con `encodeURIComponent`. `useRoute` usa ambas.
