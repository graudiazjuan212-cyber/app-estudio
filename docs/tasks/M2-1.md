### `types.ts`
```ts
export type Confidence = 'duda' | 'bastante' | 'seguro';
export type FlashRating = 'otra' | 'dificil' | 'bien' | 'facil';
export interface Attempt {
  attemptId: string; itemId: string; itemGen: number;
  subjectId: string; chapterId: string; blockId: string; tipo: ItemType;
  at: string;            // instante ISO UTC terminado en 'Z' (p. ej. "2026-11-24T10:00:00.000Z")
  studyDay: string;      // "YYYY-MM-DD", asignado al responder (ADR-008)
  tz: string;            // zona IANA
  correct: boolean; dontKnow: boolean;
  confidence: Confidence | null; rating: FlashRating | null;
  durationMs: number; sessionId: string; packVersion: number; schedulerVersion: number;
}
export interface ItemState { itemId: string; itemGen: number; card: StoredCard }
```
`StoredCard` = los campos de `Card` de `ts-fsrs` con las fechas como cadenas ISO (serializable a IndexedDB/JSON); funciones `toStoredCard(card)` / `fromStoredCard(stored)` inversas exactas.

`validateAttempt(a: Attempt): string[]` → lista de problemas (vacía = válido), mensajes en inglés cortos. Reglas: `at` es ISO válido terminado en `Z`; `studyDay` con forma `YYYY-MM-DD`; `durationMs` entero ≥ 0; `itemGen` y `packVersion` enteros ≥ 1; `tipo === 'info'` ⇒ `correct: true`, `dontKnow: false`, `confidence: null`, `rating: null`; `tipo === 'flashcard'` ⇒ `rating` no nulo, `confidence: null`, `dontKnow: false`, `correct === (rating !== 'otra')`; resto de tipos evaluables ⇒ `rating: null`; `dontKnow: true` ⇒ `correct: false` y `confidence: null`; si `dontKnow: false` ⇒ `confidence` no nulo.

### `time.ts`
- `studyDay(instant: string | Date, tz: string): string` — fecha local `YYYY-MM-DD` de `tz` con corte a las 04:00 **de la hora de pared local**: si la hora local es < 4, la fecha es la del día anterior. Con `Intl.DateTimeFormat` (hora `h23`), sin restar horas fijas (los cambios de hora no deben mover el corte). Zona inválida o instante inválido ⇒ lanza `Error`.
- `nextCutoff(instant: string | Date, tz: string): string` — el instante ISO UTC (con `Z`, milisegundos `.000`) en que empieza el siguiente día de estudio (las 04:00 locales del día siguiente al `studyDay` de `instant`).

### `grade.ts`
Respuestas (todas referencian **índices del orden original del paquete**, porque la UI baraja):
```ts
export type Answer =
  | { tipo: 'test'; selected: number }
  | { tipo: 'multi'; selected: number[] }
  | { tipo: 'vf'; value: boolean }
  | { tipo: 'ordenar'; order: number[] }              // índices de pasos en el orden elegido por Juan
  | { tipo: 'emparejar'; pairs: [number, number][] }  // [índice izquierda, índice derecha]
  | { tipo: 'huecos'; chosen: number[] }              // chosen[k] = índice de opción elegida en huecos[k] (orden del array `huecos`)
  | { tipo: 'error'; step: number };
export type GradeResult = { ok: true; correct: boolean } | { ok: false; reason: string };
export function grade(item: Item, answer: Answer): GradeResult;
export function ratingToCorrect(r: FlashRating): boolean;   // 'otra' ⇒ false
```
Reglas: acierto solo si **todo** es correcto (`multi`: conjunto exacto; `ordenar`: `order` es exactamente `[0..n-1]`; `emparejar`: `pairs` tiene `n` elementos, cada izquierda `i` emparejada con derecha `i`, sin repetir ninguno; `huecos`: todos los huecos con la opción correcta; `error`: el paso marcado es el único `incorrecto`). **Fallar cerrado**: respuesta malformada (tipo distinto del ítem, índice fuera de rango, duplicados, longitud incorrecta, `NaN`, no entero) o `item.tipo` `info`/`flashcard` ⇒ `{ ok: false, reason }`, **nunca** `correct: true`. `grade` no muta sus argumentos.

### `scheduler.ts` (FSRS)
```ts
export function fsrsRating(a: Attempt): 1 | 2 | 3 | 4 | null;   // null = no programa (info)
export function newItemState(itemId: string, itemGen: number): ItemState;   // card vacía; due = su primer instante lo fija el primer intento
export function applyAttempt(prev: ItemState | null, a: Attempt): { state: ItemState; needsRebuild: boolean };
```
- Mapeo (BRIEF §5.3): fallo o «No lo sé» ⇒ 1 (Again); acierto con `duda` ⇒ 2 (Hard); `bastante` ⇒ 3 (Good); `seguro` ⇒ 4 (Easy). Flashcard directo: `otra`=1, `dificil`=2, `bien`=3, `facil`=4. `info` ⇒ `null`.
- `applyAttempt`: ignora (devuelve `prev` sin cambios, `needsRebuild: false`) `info`; usa `a.at` como instante de repaso; si `prev` es `null` crea la tarjeta con `createEmptyCard(a.at)`; si `prev.itemGen !== a.itemGen` o `prev.itemId !== a.itemId` ⇒ lanza `Error`; si `a.at` es **anterior** al último repaso de `prev` ⇒ devuelve `prev` sin cambios y `needsRebuild: true` (ADR-003: dos pestañas; la reconstrucción ordena por instante). No muta `prev`. Parámetros: `generatorParameters(studyConfig.fsrs)`; `fsrs(...)` se crea con una función (no al importar el módulo).
- `isDue(state, now: string, tz: string): boolean` — vence antes del **próximo corte** ≥ `now` (es decir `due < nextCutoff(now, tz)`).
